## 🗄️ الربط مع قاعدة البيانات (Hostinger MySQL)
تم ربط التطبيق بشكل كامل ومباشر مع قاعدة بيانات **MySQL**:
- **قاعدة البيانات (Database Name):** `u895506237_wahib`
- **المستخدم (User):** `u895506237_wahib`
- **خادم قاعدة البيانات (Host):** `srv898.hstgr.io` (للاتصال عن بُعد) و `127.0.0.1` / `localhost` (داخل الخادم).
- **المنفذ (Port):** `3306`

### الجداول المُنشأة تلقائياً (`schema.sql`):
1. **`clients`**: إدارة الزبائن الدائمين (الاسم، الهاتف، نوع النشاط، تاريخ التسجيل).
2. **`client_prices`**: حفظ وتذكر الأسعار الخاصة لكل زبون حسب السلعة تلقائياً.
3. **`invoices`**: حفظ وتخزين جميع الفواتير الصادرة وتفاصيلها وسلعها ومجموع الوزن والمبالغ.
4. **`settings`**: تخزين إعدادات النظام والرمز السري الإداري `admin_pin`.

### معمارية المزامنة الهجينة (Hybrid Offline-First Sync):
- عند توفر اتصال، يتم الحفظ فوراً في قاعدة بيانات **MySQL** بالإضافة إلى التخزين المحلي.
- في حالة غياب الإنترنت أو ضعف الشبكة، يعمل التطبيق بسلاسة تامة أوفلاين ويتم حفظ البيانات محلياً، ثم مزامنتها بضغطة زر عبر زر **`مزامنة`** في الشريط العلوي.
- مؤشر حالة مباشر أعلى الشاشة يوضح اتصال قاعدة البيانات (🟢 `متصل بـ MySQL`).

## 📱 شريط التنقل السفلي المطور (Bottom Navigation - 4 أقسام رئيسية)
1. **`فاتورة جديدة`** (إعداد الفاتورة بنظام خطوات متسلسل ومدروس: الزبون ➔ التاريخ ➔ السلع ➔ الطباعة).
2. **`الزبائن`** (قسم مخصص لإدارة الزبائن: بحث، إضافة، تعديل، اتصال، وبدء فاتورة مباشرة).
3. **`السجل`** (سجل الفواتير السابقة مع زر طباعة مباشر لكل فاتورة).
4. **`التقارير`** (المؤشرات، المبيعات الإجمالية، الأوزان، ومشتريات الزبائن).

## 👥 قسم إدارة الزبائن (`Clients Manager`)
- **سجل شامل للزبائن التجاريين:** بطاقات أنيقة لكل زبون توضح الاسم، رقم الهاتف، ونوع النشاط التجاري.
- **محرك بحث فوري وفلاتر بالأنشطة:** تصفية فورية حسب نوع النشاط (`مطعم`، `سناك`، `شواية`، `تاجر جملة`، `تموين حفلات`، إلخ).
- **إحصائيات كل زبون:** حساب فوري لعدد الفواتير الإجمالي ومجموع المشتريات بالدرهم لكل زبون.
- **إجراءات سريعة لكل زبون:**
  - زر **`فاتورة`**: لبدء فاتورة جديدة لهذا الزبون مباشرة دون الحاجة للبحث عنه مجدداً.
  - زر **`تعديل`**: لتعديل اسم الزبون، هاتفه، أو نوع نشاطه.
  - زر **`حذف`**: لحذف الزبون عند الرغبة.
  - نقرة مباشرة على رقم الهاتف للاتصال الهاتفي السريع.
